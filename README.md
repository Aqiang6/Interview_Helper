# HR Agent · AI 全栈智能面试系统

## 🎯 项目是什么（简单介绍）
一个给求职者练手用的 **AI 模拟面试官**：
- 内置腾讯校招 4 个技术岗 JD：**AI 全栈工程师 / AI Agent 开发工程师 / AI 应用工程师 / 后台开发工程师**
- 你上传（或粘贴）简历 → AI 根据岗位 JD 自动规划面试题 → 每题答完自动评估你的回答质量 → 决定**追问当前话题 / 切下一个话题 / 结束面试**
- 最后根据你答崩的地方，给出**薄弱知识点改进建议**
- 支持 **PDF 文件 / 纯文本粘贴 / 扫描件 OCR** 三种简历输入方式；你可以自由填写 API Key、Base URL、模型名，使用任意 OpenAI 兼容大模型（DeepSeek / 硅基流动 / 阿里云百炼 / 本地 Ollama 等都可以）

---

## 🚀 怎么启动

### 方式一（Windows 用户推荐）
直接双击项目根目录下的 **`start_app.bat`**，脚本会自动安装依赖、启动服务、打开浏览器。

### 方式二（手动启动）
```bash
cd /d "d:\HR Agent"
pip install -e .
python -m ai_interviewer.app
```

启动完，浏览器打开 **http://localhost:8000** 就能用。

## 📖 使用步骤（4 步走完一场面试）

### Step 1｜配大模型
填好 **API Key / Base URL / 模型名** → 点「测试连接」确认配置没问题 → 点「下一步：上传简历」。

### Step 2｜上传简历 + 选岗位
- **默认打开「上传 PDF」Tab**：选好 PDF 后系统会**自动开始解析**（不需要再点一次按钮；失败再点「重新解析简历」重试），过程中不会乱切到其他 Tab
- 扫描件 / 图片型 PDF 识别不出来，直接切到「粘贴文本」Tab → 把简历内容复制粘贴进去 → 点「解析简历」
- 解析成功后在卡片里确认「当前目标岗位」对不对，需要换岗位就从下拉框里选

### Step 3｜开始答题
- 点「开始面试」按钮 → 立刻进入聊天页
- 聊天区先显示 **📖 面试官正在认真阅读你的简历**（后台在排面试计划，几秒钟）→ 切换到 **👨‍💼 面试官正在输入** → 出第一题
- 在输入框里回答 → 点「发送答案」→ AI 评估后自动出下一题
- 想提前结束：点顶部「结束面试并查看报告」

### Step 4｜看改进建议
面试结束后会自动展示你的**薄弱知识点改进建议**（按话题分组，给出具体学习方向），看完可以点「重新开始」再来一轮。
